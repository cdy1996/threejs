为什么「自动连接」不需要拼接瓦片

传统 tilemap 的自动拼接（autotile）靠查表：看四邻居是否存在，用 4 位掩码去图集里选对应变体，瓦片之间靠美工保证无缝。本项目走的是另一条路——把每格变成一个距离场，两个场用 smin（平滑最小值）取并集，相邻格的轮廓在数学上自动融合成一条连续光滑的海岸线，零贴图、零拼接规则。三条路线的取舍：

维度SDF 平滑并集（本项目）bitmask 自动瓦片Marching Squares
连接质量完全光滑，颈部可调取决于美工，斜角需 Wang 角片分段线性光滑
资源需求零贴图，纯代码16 片（4-bit）或 47 片（8-bit blob）图集零
运行成本每次编辑重算 97² × 层数标量场每格一次查表，最便宜每格查 16 案例表
最适合3D 造岛 / 黏土风连续地形2D 像素 / 战术地图2D 矢量地形 / 液体
学习路径建议：步骤 1 → 2 → 3 是「连接」的主线（数据 → 单格形状 → 并集）；步骤 4 → 5 是「质感与高度」；步骤 6 收口到渲染；步骤 7 用真实模块把整条管道跑起来，随手验证前面每一课。

单格形状 · 圆角盒距离场STEP 2 · ROUNDED-BOX SDF

每一格在数学上是一个带圆角的方块。距离场（SDF）上，格子内部为负、边界为零、外部为正——负得越深，离边界越远。

本页目标：亲手算一遍圆角盒距离场；理解为什么「面距 0.7925 > 半格距 0.6625」是相邻格能连上的物理基础。

2.1 一行代码，一个格子

terrain.js:23-24 · 每格先算出圆角盒距离场，再按层数灌进各标量层var c = nearby[i], core = STEP*.5 - .31;          // core = 0.3525，内核半宽
var qx = Math.abs(wx - c.x*STEP) - core,                // 到格心的横向偏移，扣掉内核
    qz = Math.abs(wz - c.z*STEP) - core;
var d = Math.sqrt(Math.max(qx,0)*Math.max(qx,0) + Math.max(qz,0)*Math.max(qz,0))
        + Math.min(Math.max(qx,qz),0) - .44;                        // - .44 即圆角半径

这是 Inigo Quilez 的圆角盒标准形式，拆开看：

d = ‖max(q, 0)‖₂ + min(max(qx, qz), 0) − r　　（q = |p − 格心| − core，r = 0.44）
  • 第一项 ‖max(q,0)‖₂：在方块外部时，是到矩形边的欧氏距离（外部为正）；
  • 第二项 min(max(qx,qz),0)：在方块内部时，是负的"嵌入深度"；
  • − r：把四个直角磨成半径 r 的圆角，同时让整个边界向外扩 r。

于是格子的"面距"（中心到边界的距离）= core + r = 0.3525 + 0.44 = 0.7925，而格心间距只有 STEP = 1.325。因为 0.7925 > 1.325 / 2 = 0.6625，相邻两个格子的"身体"必然互相侵入——这就是它们能连上的物理基础，与 smin 无关。

改参铁律：动 STEP、core、r 任何一个，都要重算 core + r > STEP / 2。原版三个数（1.325 / 0.3525 / 0.44）是配套调过的，颈部宽度、海岸饱满度都指向同一组视觉。

自动连接 · smin 平滑并集STEP 3 · SMOOTH MINIMUM

两个格子的距离场放在一起，怎么合成一个岛？min() 能连但有折角，smin() 把折角抹圆——这就是"自动地形连接"的全部秘密。

本页目标：左右对比 min 与 smin 的海岸轮廓；用 k 和格距两个滑块，亲眼看到"折角变圆角"和"缝隙搭桥"两种能力。

3.1 核心就一行

terrain.js:8 · 平滑最小值（smooth minimum）function smin(a, b, k){
  var h = Math.max(k - Math.abs(a-b), 0) / k;
  return Math.min(a, b) - h*h*k*.25;
}
  • 两个场值相差超过 k 时，h = 0，退化为 min（远处的格子互不干扰）；
  • 相差在 k 以内时，按 h² 权重把并集结果往下压最多 k/4——压出来的"多余的负值"填平了 min 会有的折角；
  • 每格按层数把自己的场并进第 0..h−1 层（terrain.js:26）：for(var l=0; l<c.h; l++) out[l] = smin(out[l], d, .72)。

3.2 两种能力的临界点

设两格中心距为 g。每个格子在中点处的场值是 v = g/2 − 0.7925：

min 断开临界：v ≥ 0 ⇒ g ≥ 2 × 0.7925 = 1.585　｜　smin 搭桥临界：v − k/4 < 0 ⇒ g < 2 × (0.7925 + k/4)

本项目 k = 0.72，搭桥极限 g < 1.945；而格距 1.325 早已保证重叠。所以原版里 smin 的真正工作是"倒圆角"——把 min 在颈部形成的尖角（剖面看是一道折线，顶点色里会显出一道"假悬崖"）修成光滑过渡；搭桥能力是白送的保险。

观察要点：项目参数（k=0.72, g=1.325）下，两格中点场值 −0.13，smin 后 −0.31——连接体现在轮廓连续光滑，而不是中部凹陷。颈部深度只影响轮廓在"湾口"处的圆润度；min 在这里会留下一个尖尖的向内折角。

有机化 · 域扭曲与高斯模糊STEP 4 · DOMAIN WARP & GAUSSIAN BLUR

圆角盒 + smin 出来的岛还是"方方的"。两道后续工序让它长出有机的海岸：域扭曲整体推移轮廓，高斯模糊抹平残留格感。

本页目标：用开关反复对比，看清每道工序贡献了什么；理解原版注释那句关键的话——"平滑的是共享标量层，不是各个格子的 mesh"。

4.1 域扭曲：采样前先把坐标系揉一下

terrain.js:20 · 所有格子共用同一个扭曲量，整条海岸线 coherent 变形var wx = x + noise(x*.65, z*.65, seed) * .06,
    wz = z + noise(z*.71, x*.71, seed+17) * .06;

不是给每个格子单独抖动（那样格与格会"各扭各的"，露出马脚），而是采样坐标本身被一张连续的噪声场推移——相邻采样点拿到的扭曲量几乎相同，于是整条海岸线像被风吹的布一样整体起伏。扭曲幅度只有 0.06，刚好够破掉笔直感，又不至于撕裂轮廓。

实验 4 · 开关对照teach-field.js · 与 terrain.js 同公式

建议顺序：先关模糊——海岸出现方格台阶与尖角（"格感"）；再开模糊——台阶变圆滑；再开关扭曲对比——扭曲让整条海岸线起波浪，而不只是抖边。

为什么模糊"共享标量层"是零接缝的关键：如果先给每格单独建 mesh 再各自平滑，两个 mesh 在交界处会各扭各的，永远对不齐。原版把所有格子的距离场先融合进同一张 97² 的标量层（terrain.js:31-36），模糊只作用于这一张共享图层——格界在数据层面根本不存在，接缝自然无从谈起。

抬高地形 · 层叠等高线STEP 5 · STACKED CONTOURS

抬高不是"把格子拉高"，而是让这个格子多参加一层标量场。每层是一条闭合等高线，高度是各层 smoothstep 的累加——梯田山体就这样长出来。

本页目标：拖动层数滑块，同时看俯视图、纵剖面和 smoothstep 曲线三个视角，理解"整数层数如何变成连续光滑的高度"。

5.1 层数怎么进入距离场

terrain.js:26 · 格子的场按层数灌进第 0..h-1 层（每层一次 smin 并集）for(var l = 0; l < c.h; l++) out[l] = smin(out[l], d, .72);

h = 3 的格子，会同时出现在第 0、1、2 三个标量层里。第 0 层是海滩基底，往上每多一层就多一条环绕它的等高线。

5.2 高度 = 各层 smoothstep 贡献的累加

terrain.js:51-53 · 高度累加公式var y = -1.1;                                    // 海床基准
y += 1.34 * (1 - smooth(-.13, .65, d[0]));      // 第 0 层：海滩，抬 1.34
for(var l = 1; l < max; l++)
  y += .86 * (1 - smooth(-.24, .23, d[l]));    // 之上每层抬 0.86 ⇒ 梯田

smooth(a,b,x) 就是 smoothstep：在阈值区间内做 S 形过渡。层场值 d 远小于下界时贡献满额（整层抬起来），远大于上界时贡献为 0（这层还没出现）。层数 h 是整数阶梯，smoothstep 负责把每级台阶的边缘磨圆——所以从侧面看是柔和梯田，从顶视图看是一圈圈闭合等高线。
